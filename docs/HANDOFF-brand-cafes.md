# 스타벅스·투썸플레이스 매장 층 — 인수 메모 (v54, 2026-11-20)

새 채팅에서 이어받을 때 이 파일과 `NOTES.md` 마지막 항목만 읽으면 됩니다.

## 1. 요청과 결정
- 사용자 요청: "기본적인 카페 정보가 있으면 좋겠다. 전국의 투썸플레이스와 스타벅스 카페 정보 입력을 원해."
- **사용자와 정한 것**
  | 항목 | 결정 |
  |---|---|
  | 자료 방식 | 공공데이터 파일을 **PC에서 걸러 오기**(앱이 인터넷에서 실시간 조회하는 방식은 선택 안 함) |
  | 표시 방식 | **내 카페 목록과 따로 지도 위 별도 층**. 점 → 카드 → [내 장소로 추가] (수천 곳을 내 목록·백업에 넣는 방식은 선택 안 함) |
- 자료원: 공공데이터포털 「소상공인시장진흥공단_상가(상권)정보」(`https://www.data.go.kr/data/15083033/fileData.do`). CSV, 분기 갱신, 이용허락범위 제한 없음, 최근 수정 2026-10-30(2026-11-20 확인). 항목: 상호명·업종명·지번주소·도로명주소·경도·위도(지점명 열은 확인 못 함 → 스크립트가 있으면 쓰고 없으면 건너뜀). **전화·영업시간 없음.**
- 하지 않은 것: 스타벅스·투썸 홈페이지(매장 찾기) 대량 수집 — 약관·차단 위험. 샌드박스에서는 data.go.kr·overpass·브랜드 사이트 모두 접속 불가(HTTP 000).

## 2. 자료 흐름
`공공데이터 CSV/ZIP` → (사용자 PC) `python scripts/filter-brand-cafes.py 받은파일.zip` → `brandcafes.json` + `brandcafes-check.csv` → 채팅에 업로드 → **`www/data/brandcafes.json`** 에 넣기 → 앱이 `fetch('data/brandcafes.json')`.
- JSON 모양: `{"v":1,"src":"…","asof":"2026-10","b":["스타벅스","투썸플레이스"],"r":[[브랜드번호,"매장명","주소",위도,경도],…]}`
- 스크립트 규칙: 상호명(공백·대소문자 무시) **맨 앞**이 스타벅스/STARBUCKS/투썸플레이스/투썸/A TWOSOME PLACE 이고, 업종 열에 '카페'·'커피'가 있으며, 좌표가 우리나라 안인 줄만. 같은 브랜드·이름·좌표 중복 제거. 가짜 자료(UTF-8·CP949·ZIP·폴더)로 시험했고, 사용자가 실제 자료로 한 번 돌려 성공함(스타벅스 2,256 · 투썸 1,525, 기준 2026-09). 사용자가 `받은파일.zip` 예시 이름을 그대로 입력해 오류가 난 적이 있어, 없는 파일이면 안내 문구가 나오고 폴더(`.`)째 실행해도 `brandcafes-check.csv` 는 입력에서 제외하도록 고침.

## 3. 앱 구조 (`www/app.js`, 모임 장소 구역)
- 상태/상수: `MP_BR_LS`('bf.mapbrand', 'off'만 끔) · `MP_BR_MINZ`=13 · `MP_BR_MAX`=900 · `MP_BR_CELL`=0.05(격자 색인).
- `mpBrLoad`(자료 읽기·정리·격자) · `mpBrDraw`(보이는 범위+40%의 점을 캔버스 `circleMarker` 로, 전용 층 `mpBr` z=395) · `mpBrPal`(브랜드·테마색) · `mpBrSelect`(카드) · `mpBrHave`(내 목록 중복: 40m·이름 앞 3글자) · `mpBrHintSync`(안내 문구).
- 카드 규칙: `mpRenderCard` 는 언제나 매장 선택(고리)을 푼다 → 매장 카드는 `mpBrSelect` 가 그 뒤에 직접 그린다. 양식 열림·위치 고르는 중에는 점을 눌러도 무시.
- `mpOpenForm(p, asNew)`: `asNew` 이면 p 를 미리 채움 값으로만 쓰고 새 장소로 저장(삭제 단추 숨김).
- `style.css`: `.mp-br`(단추) · `.mp-bhint` · `.mp-bd` · `.mp-c-src`; 펼침에서 카드 최대 높이 계산에 단추 자리 반영.
- `sw.js`: `data/brandcafes.json` 은 ASSETS 가 아니라 **선택 캐시**(없어도 설치 실패 안 함).
