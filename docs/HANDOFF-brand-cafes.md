## 2. 자료 흐름
`공공데이터 CSV/ZIP(전국, 16개 파일)` → (사용자 PC) `python filter-cafes.py .` → `cafes.json` + `cafes-check.csv` → 채팅에 업로드 → **`www/data/cafes.json`** 에 넣기 → 버전 올려 빌드·재설치.
- JSON(v2): `{"v":2,"src","asof":"2026-09","b":[브랜드 이름…],"full":["서울"],"bb":[남,서,북,동],"r":[[브랜드번호,"이름","주소",위도,경도],…]}` — 브랜드번호 **-1 = 개인 카페**, `bb` = 전부 담은 지역의 위·경도 범위(서울 밖 안내에 씀), `full` = 그 지역 이름.
- 스크립트 규칙(`scripts/filter-cafes.py`, 표준 라이브러리만): ① 업종 열에 '카페'·'커피'가 있고, 소분류 열이 있으면 **소분류가 '카페'(코드 I21201)** 인 곳만(독서실/스터디 카페 R10202, 빙수, 빵집 등 제외) ② 이름에 스터디카페·독서실·스터디룸이 있으면 제외 ③ '업소명없음' → '이름 없는 카페' ④ `--all-in`(기본 서울) 지역은 모든 카페, 그 밖은 `--everywhere`(기본 스타벅스·투썸) 브랜드만 ⑤ 프랜차이즈 = 상호명(공백·특수문자 없앤 뒤)이 `FRANCHISES` 목록의 접두어로 시작(앞의 '카페·커피' 떼고도 한 번 더) — 목록 밖은 개인 ⑥ 좌표가 우리나라 밖이거나 없으면 제외 ⑦ (이름·좌표 4자리)가 같으면 한 곳으로.
- **현재 들어 있는 자료(2026-11-21, 자료 기준 2026-09):** 합계 24,534곳 · 2.3MB — 서울 21,837곳(프랜차이즈 5,832 + 개인 16,005) + 서울 밖 2,697곳(스타벅스·투썸). (v59에서 이름에 '보드게임'이 든 17곳이, v60에서 '올리브보드카페'·'히어로보드카페' 2곳이 보드게임 층으로 옮겨져 24,553 → 24,534.) 서울 구별 381(도봉)~2,056(강남)곳. 업종은 '카페'(I21201)만. 첫 실행(소분류 거르기 전)에는 독서실/스터디 카페 2,723곳과 빙수·빵집 등이 섞여 있어(서울 24,672곳) 스크립트를 고쳐 다시 만들었다 — 이번 실행에서 뺀 업종은 스터디카페 10,768(전국) · 빵/도넛 202 · 빙수 164 등. 남은 이름 중 '스터디'가 든 7곳은 메가스터디 타워점·더빅스터디 같은 실제 카페라 그대로 둠.
- 서울 카페의 약 4분의 1(5,485곳)이 **같은 좌표에 겹쳐** 있다(한 점에 31곳도 있음) → 카드의 '같은 자리 근처 카페' 단추(최대 40곳)로 고른다.
- "개인"의 한계: 목록에 없는 작은 체인(바나프레소·디저트39 등은 추가함)이 섞인다. 같은 이름이 여러 곳이면 `FRANCHISES` 에 한 줄 추가하면 됨.

## 3. 앱 구조 (`www/app.js`, 모임 장소 구역)
- 상수/상태: `MP_BR_LS`('bf.mapbrand', 'off'만 끔) · `MP_BRF_LS`('bf.mapbrandf': all|fr|ind) · `MP_BR_FILES`(cafes.json → brandcafes.json 순서로 찾음) · `MP_BR_MINZ`=15 · `MP_BR_MAX`=900 · `MP_BR_CELL`=0.05(격자 색인).
- `mpBrLoad`(자료 읽기·정리·격자·`hasInd`·`bb`·`outB`) · `mpBrFilt`(저장값, 개인이 없는 자료면 늘 all) · `mpBrDraw`(보이는 범위+40%, **종류로 거른 뒤 900곳 제한**) · `mpBrHintSync`(오류/확대/제한/서울 밖 안내, 앞의 것이 우선) · `mpBrPal`(모든 카페 한 색 — 밝음 #8a5a3c · 세피아 #7a4f33 · 야간 #d9a577) · `mpBrNear`(15m 안 겹친 카페, 지금 종류만, 최대 40곳, 카드 안에서 스크롤) · `mpBrSelect`(카드) · `mpBrHave`(내 장소에 이미 있나: 프랜차이즈는 브랜드명, 개인은 자기 이름 앞 3글자로 40m 안 비교).
- 알약 `#mp-bf`(buildMp, 카페 단추 왼쪽), 카드는 `mpRenderCard` 가 늘 매장 선택(고리)을 푼 뒤 `mpBrSelect` 가 직접 그림. 종류를 바꾸면 걸러져 사라질 카드는 닫음.
- 내 장소 색: `MP_COLOR_NAME`(0=기본 + 8색) · `mpClean` 의 `col`(정수 1~8만 인정, 아니면 0) · `mpIcon(kind, col)`(클래스 `c1`~`c8`) · `mpFormCol`/`mpSyncCol`(입력 화면 `#mp-f-col`, role=radiogroup) · `mpFormSnap` 에 색 포함(작성 중 판단). 백업은 `places` 에 `col` 이 그대로 들어가고, 예전 백업은 0.
- `style.css`: `#mp { --pc1~8 }`(밝음·세피아·야간), `.mp-pin.cN .pn`, `#mp .mp-pin.sel.cN .pn`(야간의 선택 색 규칙보다 앞서도록 `#mp` 접두), `.mp-bf`, `.mp-sw`/`.mp-swb`, `.mp-c-near`/`.mp-nb`; 펼침에서 `.mp-br`·`.mp-bf` 는 top 158px.
- `sw.js`: `data/cafes.json`·`data/brandcafes.json` 은 ASSETS 가 아니라 **선택 캐시**(없어도 설치 실패 안 함).

## 7. 보드게임 카페 층 (v59)
- **요청(2026-11-21):** 보드게임 카페도 모임 장소 지도에 넣기. **사용자 결정:** 별도 층 + 별도 단추, 서울만, (꿈미학교와는 지금 무관한 개인 용도).
- 자료: `www/data/boardgame.json` = `{v:1, src, asof, full:['서울'], bb:[남,서,북,동], r:[[이름, 주소, 위도, 경도],…]}`. **`scripts/filter-cafes.py` 가 `cafes.json` 과 같은 실행에서 함께 만든다**(옵션 `--bg-in 서울`·`--bg-extra 이름`·`--bg-out boardgame.json|none`). 확인용 `boardgame-check.csv`(업종 열 포함).
- 고르는 규칙: 상호명에 `보드게임`(공백·영문 BOARD GAME 포함)이 든 줄을 **업종과 무관하게** 모은다(카페로 등록된 곳도, 오락장으로 등록된 곳도 있어서). 업종에 소매·학원·교육·제조·임대·수리·부동산 등이 있거나 이름에 학원·교습·제작·공방·도매가 있으면 뺀다. 같은 가게는 한 번만. **보드게임 이름이 든 곳은 `cafes.json` 에서는 빠진다**(점이 겹치지 않게). `보드카페`는 스노보드 카페 등과 헷갈려 일부러 규칙에서 뺐다 → 이름에 보드게임이 없는 가게(예: 체인 이름)는 `--bg-extra` 로 더한다.
- 한계: **이름으로 고르므로** 이름에 '보드게임'이 없는 보드게임 카페는 빠진다. 업종 이름은 파일마다 달라 실제 파일의 업종 분포(스크립트 출력 "보드게임 카페" 구역)로 확인해야 한다.
- 앱(`www/app.js`, `mpBg*`): `MP_BG_LS`('bf.mapbg', 'off' 만 끔, 기본 켬) · `MP_BG_FILE` · `MP_BG_MINZ`=13(카페는 15) · `MP_BG_MAX`=600. 점은 **카페 층과 같은 캔버스(`mpBrRend`)** 에 그린다(캔버스를 둘 겹치면 위쪽 것만 눌러져서). `mpBrDraw` 끝에서 `mpBgDraw` 를 호출해 보드게임 점이 늘 위에 오게 함. 점 반지름 7(카페 6.5, 선택 고리 12). 색 보라(밝음 #5d4fa8 · 세피아 #5b4a8c · 야간 #b4a6f2).
- 단추 `#mp-bg`(주사위, 카페 단추 바로 아래: 좁은 화면 top 118px, 펼침 212px). **자료 파일이 없으면(404) 단추도 숨기고 안내도 없다**(읽는 중에도 숨김). 자료가 깨지면 단추는 보이고 안내 "보드게임 카페 자료를 불러오지 못했습니다."
- 안내 문구 `mpBrHintSync` 는 두 층을 함께 본다: 켜진 층이 모두 안 그려지는 확대면 "지도를 확대하면 장소가 보입니다", 보드게임만 보이는 확대(13~14)면 "커피 카페는 더 확대하면 보입니다", 담긴 지역 밖이면 "보드게임 카페는 서울만 담겨 있습니다"(카페 층 안내가 있으면 그쪽이 먼저).
- 카드(`mpBgSelect`): 이름·주소·같은 자리 근처 목록·(접힌) 정보 칸·단추 4개 `정보 보기`·`길찾기`(네이버 지도, v61)·`나만의 리뷰`·`내 장소로 추가`(v72: 예전에 주소 밑에 늘 보이던 "보드게임 카페 · 공공데이터(상가정보) … 기준 · 영업 여부·시간은 지도 앱에서 확인하세요" 줄은 삭제. v73: `정보 보기`는 카드 안에 펼치지 않고 네이버 지도 앱 검색 `nmap://search?query=가게 이름 + 시·군·구` 를 바로 연다 — `mpLinks().info`·`mpInfoQuery`.) 한 카드만 열리므로 `mpRenderCard` 가 카페·보드게임 선택을 함께 푼다. 같은 건물(15m 안)에 겹친 보드게임 카페는 카드에 "같은 자리 근처 보드게임 카페 N곳" 이름 단추(`mpBgNear`, 최대 20곳)가 생겨 눌러서 고른다 — 실제 자료에 4쌍(구일일보드게임카페·홈즈앤루팡 압구정, 더홀릭 수유역·왕십리역, 더홀릭 종로점·레드버튼 종로점)이 있다.

## v64 추가: 지하철 층·단추
- 지도 오른쪽 단추 묶음에 **지하철 켜기/끄기**(`#mp-sw`, 클래스 `mp-subway`, 열차 아이콘)가 생겼습니다. 저장 키 `bf.mapsubway`('off' 이면 끔, 기본 켬, 이 기기만·백업 제외). 벡터 지도에서만 보이고(`#mp:not(.mp-src-vec) .mp-subway{display:none}`) 펼침(`#mp.two`)은 오른쪽 단추 줄에서 보드게임 단추 아래(top 266, v65에서 옮김), 한 쪽 화면은 보드게임 단추 아래(top 172)입니다. 펼침의 카드는 단추 줄을 덮지 않게 오른쪽 끝을 64px 띄웁니다. (클래스 `.mp-sw` 는 핀 색 동그라미가 이미 쓰고 있어 쓰면 안 됩니다.)
- 역은 두 층입니다: `subway-merged`(앱이 타일의 역을 모아 같은 이름·700m 안을 한 곳으로 합친 GeoJSON 원 `bf-subway`) / `subway-station`(타일의 poi 를 그대로 그리는 예비). `app.js` 의 `mpSwRefresh` 가 지도가 쉴 때(`idle`) `querySourceFeatures` 로 모아 `bfMapStyle.merge` 로 합치고, 합친 역이 있으면 합친 층만 보입니다. 테마를 바꾸면 지도를 새로 만들므로 마지막 목록(`mpSwData`)을 스타일에 넣어 바로 보이게 합니다.
- 샌드박스에서는 가짜 타일(tests/vtscene.mjs, 천호 세 점)로만 확인했습니다. 실제 타일의 역 표기(name·name:ko·rank, 환승역 점 위치)와 합쳐진 결과는 실기기에서 확인해야 합니다.
