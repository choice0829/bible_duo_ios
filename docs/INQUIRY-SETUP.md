# 문의하기 설정 안내서 (v70)

머리줄의 **봉투 아이콘**을 누르면 문의하기 창이 열립니다(제목·내용·사진 → 아이폰 메일 작성 창).
v69에는 설정 안의 「문의하기」와 「후원하기」가 있었으나, **v70에서 후원하기를 모두 삭제**하고 문의하기를 설정 밖의 별도 아이콘으로 옮겼습니다.

## 1. 아이콘 위치
- 한 쪽(접은·세로) 화면: **책 이름 아래 한 줄에 8개**(검색 · 하이라이트 · 설교노트 · 바이블 포토 카드 · 모임 장소 · **문의하기** · 내 계정 · 설정), 양 끝 맞춤. 듀오 접힘(앱)은 오른쪽 가장자리를 따라 세로 한 줄(v81), v82부터 화면 아래쪽(바닥에서 16px). (v77: 4·4 두 줄 → v80: 책 이름 아래 한 줄)
- 펼친 화면: 한 줄에 7개가 같은 순서로 놓입니다.
- 줄 배치를 바꾸려면 `www/style.css`의 `.menu-row > :nth-child(…)` 규칙과 `www/app.js`의 `MENU_COUNT`·`MENU_COLS`·`MENU_ROWS` 를 함께 고칩니다.
- 책 이름이 길면 글자가 자동으로 작아집니다(최소 16px). 아이콘이 4열이 되어 책 이름 자리가 좁아졌기 때문에, 작은 폰(SE 크기)에서는 「데살로니가전·후서」가 가장 작게(16px) 보입니다.

## 2. 받는 메일 주소
- 현재 받는 주소는 `choice.seon@gmail.com` 입니다(2026-11-23 택 님이 알려 주심). 바꾸려면 `www/app.js` 안의 한 줄 `const INQUIRY_EMAIL = '…';` 의 따옴표 사이만 고치면 됩니다. 비워 두면 문의하기 화면에 「받는 메일 주소가 아직 설정되지 않아 보낼 수 없습니다」라고 나오고 보내지지 않습니다.
- **주의:** 이 저장소는 공개이고, 주소는 앱 파일 안에도 들어갑니다. 즉 **주소는 누구나 볼 수 있습니다**(스팸·광고 메일이 올 수 있음). 문의 전용 주소로 바꾸고 싶으시면 위 한 줄만 고치고 새 버전으로 다시 설치하면 됩니다.

## 3. 동작 방식
1. 머리줄의 문의하기 아이콘 → 제목(80자)·내용(2000자)을 쓰고, 사진은 최대 3장 붙입니다(큰 사진은 앱이 긴 변 1600px 안쪽으로 줄입니다).
2. 「메일로 보내기」 → 아이폰 **기본 메일 작성 창**이 받는 사람·제목(`[앱 문의] …`)·내용·사진이 채워진 채 열립니다.
3. 내용을 확인하고 **메일 작성 창의 보내기**를 한 번 더 눌러야 전달됩니다. 앱 버전과 화면 크기가 내용 끝에 자동으로 적힙니다(안내 문구에도 적어 두었습니다).
4. 보낸 뒤 앱 화면의 제목·내용·사진은 비워지고, 취소·임시 저장·실패 때는 쓰던 글이 남습니다. 창을 닫았다 다시 열어도 앱을 끌 때까지 쓰던 글이 남습니다.

### 메일 계정이 없는 아이폰
아이폰의 **메일 앱에 계정이 없으면 메일 작성 창을 열 수 없습니다**(Gmail 앱만 쓰는 경우 등). 이때 앱은 ① 받는 주소 표시·복사 ② 제목·내용 복사 ③ 「기본 메일 앱으로 열기」(mailto 링크, **사진은 붙지 않음**)를 보여 줍니다. 사진까지 보내려면 아이폰 설정 › 메일에서 계정을 추가해야 합니다.

## 4. 실기기에서 확인할 것 (PC 모의로는 확인하지 못했습니다)

| 번호 | 확인 |
|---|---|
| 1 | 접은 화면에서 아이콘 8개가 책 이름 아래 한 줄로 보이고(v80), 봉투 아이콘이 여섯째 칸에 있다. 듀오 접힘에서는 상태표시줄과 겹치지 않는다 |
| 2 | 봉투 아이콘 → 문의하기 창 → 제목·내용 입력 후 「메일로 보내기」 → 메일 작성 창이 받는 사람·제목·내용으로 채워져 열린다 |
| 3 | 사진 추가(앨범에서 고르기) → 작은 그림으로 보이고, 메일에 첨부로 붙는다. 3장 제한 · × 로 빼기 |
| 4 | 메일 작성 창에서 보내기·취소·임시 저장 → 앱 화면에 알맞은 안내가 나온다 |
| 5 | 메일 앱에 계정이 없을 때 대체 방법(주소 복사·기본 메일 앱 열기)이 보인다 |
| 6 | 키보드가 올라와도 내용 칸·보내기 단추가 가려지지 않는다 |
