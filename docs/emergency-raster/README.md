# 비상용 래스터(A) 지도 — 되살리기 안내서

> 이 폴더는 **앱에 들어가지 않습니다**(`www/` 밖). 앱 v68부터 모임 장소 지도는 **벡터(B) 하나**만 쓰고, 그림 조각(타일)을 받아 보여 주는 **래스터(A) 방식과 CARTO 열쇠 입력은 앱에서 삭제**했습니다.
> 벡터 지도가 어떤 기기에서 끝내 안 나오는 문제가 생겼을 때, 아래 순서로 래스터를 다시 넣을 수 있도록 v67의 코드를 그대로 떼어 둔 것입니다.

## 1. 지금(v68) 앱의 동작

| 상황 | v67까지 | v68 |
|---|---|---|
| 벡터 지도가 정상 | 벡터로 그림 | 같음 |
| 벡터가 안 됨(WebGL 불가·부품/자료 못 받음·15초 안에 안 그려짐) | 자동으로 래스터(OpenStreetMap)로 전환, 안내문 9초 | **지도 바탕은 비고**, 안내문이 남음. 핀·목록·길찾기는 그대로 사용. 지도를 **닫았다가 다시 열면 한 번 더 시도** |
| 고급설정 | 지도 방식(A/B) 단추, CARTO 열쇠 입력 | 없음 |
| 기기에 남은 `bf.mapeng`·`bf.mapkey` 값 | 사용 | **무시**(지우지는 않음 → 되살리면 그대로 다시 쓰임) |

## 2. 언제 되살리나 (판단 기준)

- 실기기(아이폰 듀오)에서 지도를 열었을 때 **"지도 자료를 불러오지 못했습니다 …" 안내가 인터넷이 정상인데도 계속** 뜰 때
  - 안내문 끝 괄호의 진단 한 줄(예: `스타일 ○ · 자료 주소 × · 타일 0개 · 마지막 오류: …`)을 Claude에게 그대로 알려 주세요(이 글은 비밀 정보가 아니므로 채팅에 붙여도 됩니다).
- 먼저 점검할 것: ① 인터넷 연결 ② 앱 다시 설치(Sideloadly) 뒤에도 같은지 ③ 진단 문구가 `WebGL`이면 이 기기 웹뷰가 벡터를 못 그리는 것이므로 래스터 복원이 가장 확실한 해결책입니다.

## 4. 되살린 뒤 꼭 알아 둘 것

- **OpenStreetMap 공식 타일 서버(`tile.openstreetmap.org`)는 자원봉사로 운영되며 이용 정책이 있습니다**(과도한 사용·상업적 대량 사용 제한, 올바른 출처 표기 필요). 개인 소규모 사용에는 문제가 없지만, **공개 배포 후 사용자가 늘면** 정책 위반이 될 수 있습니다. 그때는 CARTO 열쇠(무료 구간 확인) 또는 지도 타일 사업자의 유료 요금제 사용을 검토하세요. 정확한 조건은 각 사업자의 최신 약관을 확인해야 합니다.
- 래스터 복원은 **샌드박스에서 지도 서버에 접속할 수 없어** PC 모의(가짜 타일)로만 시험합니다. 색조 필터 값은 실기기에서 보고 조정해야 합니다.
- 앱 코드(Swift 또는 `www/`)가 바뀌므로 **Sideloadly로 다시 설치**해야 하고 7일 주기가 다시 시작됩니다. 설치 전에 앱의 **데이터 백업**을 먼저 하세요.
- CARTO 열쇠 등 모든 키는 **채팅에 붙여 넣지 말고** 앱 안(고급설정)에만 입력하세요.
